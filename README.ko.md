# Splendor: Renaissance Guild (스플렌더: 르네상스 길드)

> [View English Documentation (README.md)](./README.md)

**Splendor: Renaissance Guild**는 React, Vite, Express, Socket.IO로 제작한 르네상스 보석 상인 테마의 전략 보드 웹 게임입니다. 르네상스 길드 AI 상인들과 솔로 대전을 즐기거나, TV 공용 보드와 스마트폰 컨트롤러를 QR 코드로 연결해 친구들과 함께 **15 승점** 선취 경쟁을 펼칠 수 있습니다.

---

## 주요 기능

### 게임 모드
- **솔로 대전 (1인 vs AI)**: 상인 이름을 직접 설정하고 3인 또는 4인 구성으로 르네상스 길드 AI(로렌초, 베아트리체, 코시모)와 대전합니다.
- **AI 관전 모드**: 3~4명의 AI 상인들이 보석 수집·카드 구매·귀족 후원을 두고 펼치는 전략 대전을 실시간으로 관전합니다.
- **TV · 모바일 로컬 멀티플레이**: 거실 TV나 모니터에 공용 보석 은행·카드 시장·귀족 타일을 띄우고, 플레이어들은 QR 코드를 스캔해 스마트폰을 개인 손패 컨트롤러로 사용합니다.

### 비주얼 및 게임 연출
- **풀 뷰포트 르네상스 벨벳 테이블**: 깊은 플럼 벨벳 매트, 금박 테두리, 르네상스 유화풍 상인 초상화, 은은한 촛불·별빛 앰비언스로 보드게임 테이블 분위기를 구현했습니다.
- **입체 3D 보석 칩**: 두께감이 살아 있는 3D 클레이 포커칩 스택과 호버·선택 부양 효과, 포물선 3D 비행 및 보석 색상별 별빛 파티클 연출을 제공합니다.
- **맞춤형 카드 뒷면 및 플립 애니메이션**: 1·2·3단계별 르네상스 일러스트 카드 뒷면과 부드러운 카드 뒤집기 보충, 카드 구매 비행, 귀족 방문 배너 효과를 지원합니다.
- **실시간 합성 사운드**: 외부 음원 파일 없이 Web Audio API로 구현한 칩 부딪힘, 카드 드로우, 구매 차임, 턴 알림, 귀족 팡파르 효과음과 음소거 토글을 제공합니다.

## 게임 규칙 요약

자신의 턴에 아래 행동 중 **1가지**를 선택합니다.
1. **보석 토큰 채집**: 서로 다른 색 보석 **3개**를 가져오거나, 은행에 4개 이상 남은 같은 색 보석 **2개**를 가져옵니다. (보유 한도 최대 10개)
2. **개발 카드 구매**: 보유 보석과 기존 카드의 영구 보너스 할인을 활용해 시장 카드 또는 킵한 카드를 구매하여 영구 보석 보너스와 승점을 얻습니다.
3. **카드 킵(예약)**: 시장 카드 또는 덱 맨 위 카드를 최대 **3장**까지 비공개/공개 예약하고, 은행에 황금 조커가 남아 있으면 **1개**를 획득합니다.

턴 종료 시 카드 보너스 조건을 충족한 **귀족 타일**이 자동으로 방문해 **+3 승점**을 부여합니다. 누군가 **15점** 이상을 달성하면 마지막 라운드를 마친 뒤 최고 득점자가 승리합니다.

## 기술 스택

- **프론트엔드**: React 19, Vite, Lucide Icons, `qrcode.react`, Web Audio API
- **백엔드 및 실시간 통신**: Node.js, Express 5, Socket.IO
- **타이포그래피**: `Cinzel` / `Cormorant Garamond` (영문 타이틀) 및 로컬 임베드 **SB 어그로체 (`Aggravo`)** (한글 UI 및 굵은 게임 숫자)

## 실행 방법

```bash
# 의존성 설치
npm install

# 개발 서버 실행 (http://localhost:3000)
npm run dev

# 프로덕션 빌드
npm run build

# 프로덕션 서버 실행
npm start

# 린트 검사
npm run lint

# 단위 테스트 실행 (게임 규칙 및 연출 상태 diff 검증)
npx tsx --test server/game.test.js src/utils/gameEffects.test.js
```
